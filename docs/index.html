FluidDial-CYD

Web Installer for the CYD FluidNC Pendant

Requirements

  • Google Chrome or Microsoft Edge (version 89+)
  • CYD (Cheap Yellow Display) ESP32 board
  • USB data cable (not charge-only)
  • Windows, macOS, or Linux
Web Serial is not supported in Firefox or Safari. Use Chrome or Edge.

Install Firmware

v2.3.2 — Latest Release

Connect your CYD to USB, then click one of the buttons below.
Select the correct COM port when prompted.

Your browser does not support Web Serial.
Please use Chrome or Edge.

v2.2.2 Dev — Pre-Release
Unreleased test build — not supported. Only use it if you are chasing a specific problem or have been asked to try it. Keeps your settings; run Update above to go back to v2.2.1.
Update — installs the latest firmware while preserving saved settings (screen-type detection, transport choice, ESP-NOW machine pairings, jog preferences, rotation). Use this for upgrading from a previous FluidDial-CYD install. When the installer asks, leave the "Erase device" box unchecked — ticking it wipes your saved ESP-NOW pairings and you will have to pair again.

Factory Reset — wipes the entire device including all saved settings, then installs the firmware fresh. Use this for first-time installs, or to recover a pendant that will not boot cleanly. After reset you'll re-run the touch-screen detection, and on ESP-NOW you'll need to pair with your controller again.

After Installing

First boot — screen detection: the pendant will display "Capacitive — Tap the Screen" then "Resistive — Tap the Screen". Tap when your screen type is shown. The result is saved and the pendant reboots automatically — this only happens once.

Wired (UART): connect your CYD pendant to your FluidNC controller via UART (TX/RX). The pendant detects the controller automatically and displays axis positions and machine state, and allows jogging, homing, probing and spindle control.

Wireless (ESP-NOW): new in v2.2.0 — a direct encrypted radio link with no WiFi network, access point or router involved. It needs FluidNC v4.0.4 or newer on the controller. Go to FluidNC > Connection, choose ESP-NOW (the pendant reboots to apply), then tap Pair New and run $espnow/pair on the controller. Every feature works exactly as it does over UART.

The WiFi transport was removed in v2.2.0. If you rely on it, stay on v2.1.11.

See the GitHub repository for full documentation and wiring instructions.
